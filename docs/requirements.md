# 上達ノート 要件定義書

2026年11月3日時点（アプリ バージョン 2026.11.03-7）

## 1. 概要

上達ノートは、イラストを描く人が「描く → ふり返る → 課題を1つ決める → 練習する → また描く」のサイクルを回し続けるためのアプリです。作品を並べて眺める楽しさと、次の1枚で何を良くするかをはっきりさせることを両立させます。

| 項目 | 内容 |
| --- | --- |
| 対象ユーザー | 趣味・学習中のイラストレーター。スマホ中心で、PCでも描く人 |
| 解決したいこと | 描きっぱなしで上達の実感がない／課題があいまい／描きたいものが決まらない／締切を守れない |
| 提供価値 | 作品ごとの自己評価と課題の記録、課題に合った練習の提案、テーマ選びの支援、工程ごとの期日の自動計算、成長の見える化 |
| 公開版（PWA） | https://kazu-0778.github.io/joutatsu-note/ |
| リポジトリ | https://github.com/kazu-0778/joutatsu-note |
| 試作版（claude.ai） | https://claude.ai/artifact/5emCiCaXmy7kT7GEjbGVFE （仕様確認用。データは公開版と別） |

## 2. 提供形態と全体構成

基本はスマホだけで完結し、設定でユーザー自身のGoogleドライブをつなぐとPCとも連携できる構成です。運営側は作品データを預かりません。

| 対象 | 現在 | 製品版での予定 |
| --- | --- | --- |
| アプリ本体 | Webアプリ（PWA）。GitHub Pages で配信。ビルド不要の静的ファイル | 同じコードを使う |
| スマホ | ブラウザ版をホーム画面に追加して使う | Capacitor でネイティブアプリ化し、ストアで配布（端末内データを確実に残すため） |
| PC | ブラウザ版。Chrome / Edge でアプリとしてインストールできる | 同じ |
| データ保存（標準） | 端末の中（IndexedDB） | 同じ |
| データ保存（PC連携時） | ユーザーのGoogleドライブと双方向同期（実装済み） | OneDrive / Dropbox を追加 |
| AI | Claude利用者向けに claude.ai での相談へつなぐ（段階A） | 上達ノートとClaudeを直接つなぐ MCP コネクタ（段階B） |

## 3. 機能要件

### 3.1 作品の記録

- 画像（PNG / JPEG / WebP）を登録。長辺2400pxに縮小して保存し、縦横比も記録する
- タイトル、完成日、タグ（任意・複数。入力候補あり）
- 編集・削除。削除は確認画面を経る
- 入力途中の保護：記録・計画・設定の画面で保存していない入力があるとき、ウィンドウ外のクリック・Escキー・キャンセルで閉じる前に「破棄して閉じる／編集に戻る」を確認する
- 日付欄は「2026/11/03（火）」の形で曜日を表示する（Windowsの日付形式で曜日が「()」になる問題への対策）

### 3.2 自己評価

- 項目ごとに1〜5点。初期項目は構図・デッサン・線画・色彩・光と影・完成度の6つ
- 「良かった点」「気になった点」の自由記述
- 項目は設定で追加・名前変更・削除できる。並べ替えは「並び替え」ボタンを押したときだけドラッグできる（スクロール中の誤操作を防ぐ）
- 項目を消しても、過去の作品の点数と項目名は残る

### 3.3 課題とふり返り

- 完成作品ごとに「次の作品の課題」を1つ設定する（分類＋文章）
- 次の作品を記録するとき、前回の課題に対する達成度（1〜5）と反省を書く
- 反省のスキップ：「この作品では反省をスキップする」を選べる。完成日が前回の課題を決めた作品より前なら、過去作の登録とみなして自動でスキップする。スキップした課題は次の作品に持ち越す
- 課題候補の補助：今回と直近3作の平均点が低い項目から最大3つ提案する。設定でオン・オフでき、初期値はオン

### 3.4 練習アドバイス

- 課題の分類（12種類）ごとに、所要時間つきの練習メニューを表示する。AIなしで動く
- 製品版では練習メニューの中身を拡充する（他アプリとの差になる部分）

### 3.5 スケジュール

- 開始日・完成予定日・工程（初期値：ラフ20% / 線画30% / 着色35% / 仕上げ15%）を入力
- 1日の作業可能時間を平日・休日別に設定（初期値：平日2h / 休日5h、休日は曜日で指定）
- 期間中の作業可能時間の合計を配分%で分け、各工程の期日を自動計算する
- 「〇〇を完了」ボタンで工程を進め、実際の完了日を記録。「元に戻す」あり。最後の工程を終えると完成記録画面を開く
- 工程バーの各工程をタップ（PCはマウスを乗せる）すると吹き出しを出す：工程名・期間・計画時間（作業可能時間の合計×配分%）・残り時間。残り時間は、完了済みなら完了日、期日を過ぎていれば「0h（N日遅れ）」、作業中なら「期日までに使える作業時間」と計画時間の小さい方、未着手なら計画時間。ほかの場所をタップ・スクロールで閉じる
- 帯グラフで進捗と今日の位置を表示し、遅れ日数と残り作業可能時間を出す

### 3.6 テーマ選び（お題ガチャ）

- 制作計画の画面に「テーマ」欄と「お題ガチャを引く」ボタンを置く
- 3つの枠から1語ずつ出す：だれ・何／どこ・状況／雰囲気。どこ・状況と雰囲気には季節・色・テーマの言葉（約束、秘密など）も含め、今の季節の語は出やすくする（約30%）
- 枠ごとに「固定」「引き直す」ができ、「ぜんぶ引き直す」は固定した枠を残す
- 練習ポイント：いまの課題の分類から自動で添える（例：構図 → 三分割構図で）。チェックで外せる。言葉の欄と同じく「固定」「引き直す」ができ、固定中は「ぜんぶ引き直す」でも変わらない
- 描く範囲の目安：作業可能時間から決める（6時間未満：バストアップ・1人／6〜15時間：腰上〜全身・1人、簡単な背景／15時間超：全身・背景あり（2人まで））
- 「このお題で描く」でテーマ欄に入れ、タイトルが空なら仮タイトルも入れる。ガチャ由来の作品には「#お題ガチャ」タグを付ける
- Claude利用者（設定「Claudeを使っている」がオン）には「Claudeで相談する」「相談文をコピー」を出す。相談文はお題・練習ポイント・描く範囲・今の課題・制作期間と作業時間・最近の作品とタグを含み、一問一答（1回1問・全3問）のあとテーマ案を3つ出してもらう
  - 質問と案の選択は、Claudeの選択肢入力ツール（ask_user_input など）の単一選択で1問ずつ出すよう依頼する。ツールが使えない場合に限り A〜D の記号付きの文章で出し、記号だけで答える（ツールが出るかはClaude側の環境しだい）
  - 案を選んだら、Claudeに決まった形式の「上達ノート用まとめ」（タイトル・テーマ・場面・構図・見せ場・練習ポイント）をコードブロックで出してもらう
- 相談結果の記録：まとめを貼り付けて取り込むと、作品に「Claudeとの相談結果」として保存する（データ項目 consult。ドライブ同期・ZIPの対象）
  - 取り込み口は2か所。制作計画の画面の「Claudeの相談結果を取り込む」（テーマ欄とタイトル（空のとき）にも入る）と、ホームの制作中スケジュールの「相談結果を記録」（その場で保存。テーマが空ならテーマにも入る）
  - 「コピーした内容を貼り付け」ボタンでクリップボードから読み込める（使えない端末では欄を長押しして貼り付け）
  - 項目名が見つからない文章を貼った場合は、メモとしてそのまま残す
  - 表示：ホームの制作中スケジュール（折りたたみ）、作品の詳細画面

### 3.7 実績からの配分提案

- 工程ごとの完了日から実際に使えた作業時間を算出し、直近5作の割合を工程名ごとに平均する
- 5%刻みで提案し、「この配分を使う」で反映。工程ごとの予定との差（平均〇日遅れ）も表示

### 3.8 成長の記録

- 数字カード4つ：記録した作品数、直近5作の平均点（前の5作との差）、課題の平均達成度、締切内に完成した数
- 自己評価の推移グラフ（平均／項目別を切替、表でも確認可）、課題ごとの達成度一覧

### 3.9 作品ギャラリー

- 作品を鑑賞することに集中する画面。同じ大きさの正方形タイルで並べる（画像は中央を切り取り、全体は詳細画面で見る）。「大きく表示」で2段階に切替
- 検索はアイコンを押したときだけ開く。絞り込み（期間・タグのいずれか／すべて・並び順）も折りたたみ
- 使用中の条件は小さなチップで表示し、個別に解除できる
- 作品をタップすると詳細：タイトル、完成日、タグ、テーマ、自己評価（★平均＋項目別＋レーダー）、反省、次の課題。←→で前後の作品へ移れる

### 3.10 設定

- 右上の歯車アイコンから開く。左下にアプリのバージョンを表示
- 保存先とバックアップへの入口、表示（ライト／ダーク／端末に合わせる、端末ごとに記憶）、自己評価の項目、Claude連携、課題候補のオン・オフ、作業可能時間と休日の曜日、工程と配分の初期値

### 3.11 バックアップ

- 画像・記録・設定をZIPファイル1つに書き出す。中身はドライブ連携時と同じフォルダ構成（5章）
- ZIPから復元。同じ作品は上書き、それ以外は残す。設定の復元は任意
- 最後にバックアップした日を表示。製品版では一定期間が空いたら促す通知を出す

### 3.12 Googleドライブ連携

- 設定 → 保存先とバックアップ →「Googleドライブと連携」。Googleでログインして許可すると、端末内のデータをドライブへ送り、以後は双方向に同期する
- 連携中は、アカウント・最終同期日時・「今すぐ同期」・「連携を解除」を表示。画面上部にも同期の状態を出す
- 仕組みの詳細は6章

### 3.13 AI連携（任意）

- 段階A（実装済み）：お題ガチャから claude.ai での相談へつなぐ（3.6）。APIの費用はかからない
- 段階B（製品版）：MCPコネクタで、Claudeが上達ノートの記録を読み、決めたテーマを制作計画として登録できるようにする

## 5. データ構成

記録は「作品1点＝1件」で持ち、制作中も完成も同じ形です。

### 5.1 作品の記録

| 項目 | 内容 |
| --- | --- |
| id | 作品の識別子 |
| status | 制作中（wip）または完成（done） |
| title / tags | タイトル、タグの一覧 |
| imageId / ar | 端末内の画像への参照、縦横比 |
| start / due / completedAt | 開始日、完成予定日、実際の完成日 |
| hours | この作品の作業可能時間（平日 / 休日） |
| phases | 工程の一覧。工程名、配分%、予定期日、作業時間、完了フラグ、実際の完了日 |
| theme | テーマ（文章、ガチャ由来か、ガチャの語・練習ポイント・描く範囲） |
| review | 項目ごとの点数、そのときの項目名、良かった点、気になった点 |
| reflection | 前回の課題（写し）、達成度、反省。スキップした場合は skipped |
| nextChallenge | 次の課題の分類と文章 |
| updatedAt | 最終更新日時（同期で新しい方を決めるのに使う） |

ドライブ上の記録では、端末内の画像参照の代わりに、ドライブ上の画像ファイルの参照（driveImage）を持ちます。

### 5.2 設定

自己評価の項目（名前と対応する練習の分類）、課題候補のオン・オフ、Claude連携のオン・オフ、作業可能時間、休日の曜日、工程と配分の初期値、最終更新日時。表示テーマ、ギャラリーの絞り込み条件、ギャラリーの表示サイズは端末ごとに保存し、同期しません。

### 5.3 フォルダ構成（ドライブ連携時とバックアップで共通）

```
上達ノート/
  作品/        <作品id>.jpg など（画像）
  記録/        <作品id>.json（作品の記録）
  設定.json
  manifest.json  （バックアップのみ。形式の版、書き出し日時）
```

ユーザーがドライブを開けば自分の作品がそのまま見られ、アプリをやめてもデータが手元に残ります。

## 6. 保存方式とPC連携

標準は端末内保存で、「Googleドライブと連携」を選んだ人だけがPCと同じデータを使えます。運営のサーバーは作品データを経由しません。

### 連携の流れ（アプリ内で表示する手順）

1. 設定 → 保存先とバックアップ →「Googleドライブと連携」を押し、Googleアカウントでログイン
2. 「上達ノートがファイルを作成・管理することを許可」を承認
3. 端末内の作品と記録をドライブへまとめてアップロード（作品数により数分）
4. PCのブラウザで上達ノートを開き、同じGoogleアカウントで連携して完了

### 同期のルール

- 権限は drive.file（このアプリが作ったファイルだけを扱う）。同意画面は「テスト中」で、登録したテストユーザーだけが連携できる
- 端末内を正とし、保存の約1.5秒後・アプリを開いたとき・画面に戻ったとき・2分ごとに同期する
- 作品1点ごとに最終更新日時を比べ、新しい方を採用する。削除は「削除済み」の記録を残して他の端末に伝え、ドライブ上の画像はゴミ箱へ移す
- Googleのログインは1時間で切れる。切れた後（または切れる5分前）の最初のタップで自動的に取り直し、同期を再開する（ブラウザの制約で、操作なしの取り直しはできない）。ログイン情報は端末内に保存し、1時間以内ならアプリを開き直しても引き継ぐ。自動の取り直しに失敗したときは画面上部の「今すぐログイン」で再開する
- 連携を解除しても、ドライブ内のデータはそのまま残し、端末内にもデータを残す
- 対応順：Googleドライブ → OneDrive / Dropbox。iCloudはPC側から扱いにくいため後回し

## 7. 非機能要件

| 分野 | 要件 |
| --- | --- |
| プライバシー | 作品と記録は端末またはユーザーのストレージにだけ保存し、運営のサーバーには置かない。ドライブはアプリが作ったファイルだけを扱う権限で使う |
| 表示 | 背景と文字は無彩色のグレー（作品の色の見え方に影響させない）。色は操作できる場所と評価だけ。ライト／ダーク両対応 |
| 画面サイズ | スマホ幅（約390px）からPC幅まで、横スクロールなしで使える |
| 操作 | 指での操作を前提に、誤操作しやすいもの（並べ替え、削除、工程完了、入力途中で閉じる）はモード切替・確認・「元に戻す」のいずれかを付ける |
| 画像 | 長辺2400pxに縮小して保存。一覧は遅延読み込み |
| オフライン | 電波がなくても開いて記録・閲覧できる（PWA）。連携時はつながったときに同期 |
| 更新の反映 | アプリ本体は開くたびにサーバーへ更新を確認する（GitHub Pages のブラウザ保存10分を回避）。設定画面にバージョンを表示 |
| アクセシビリティ | キーボードで操作できる（並べ替えは矢印キー、詳細は←→）。グラフには表の表示を用意。動きを減らす設定を尊重 |

## 8. AI連携・収益化と未決事項

アプリ本体はAIなしで完結させ、AIは任意の追加機能にします。ClaudeのPro / Maxプランを他社アプリのAI機能に使う公式の仕組みは確認できていないため、次の順で進めます。

1. 段階A（実装済み）：claude.ai での相談へつなぐ。AI費用はユーザーのClaudeプランの範囲
2. 段階B（製品版）：MCPコネクタで上達ノートの記録を読み書きできる窓口を用意する
3. 必要なら、運営がClaude APIを契約して有料プランに組み込む（軽量モデルで1回約0.1円、高性能モデルで約4円の試算）

### 収益化の候補

- スマホ版はストアの課金（アプリ内課金、手数料15〜30%）
- PCでも有料機能を使う場合は、購入状態を確認する小さな仕組み（ログインまたはライセンスキー）が必要。最初はPC連携を無料機能にする案もある

### 未決事項

- 無料と有料の境目（保存枚数、AI連携、成長グラフ、PC連携）
- 練習メニューの拡充方針（分類数、監修の有無）
- お題ガチャの語の拡充と「出てほしくない語」の設定
- claude.ai を相談文入りで開く方式が使えるかの実機確認（使えなければコピー＆貼り付け）
- OneDrive / Dropbox 対応の時期
